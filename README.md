Berikut adalah jawaban pertanyaan di modul:
1. unset table : Membungkus seluruh struktur tabel.
unset tr : Membuat baris baru dalam tabel.
unset th : Membuat sel judul (tebal & rata tengah).
unset td : Membuat sel data atau isi biasa.
2. unset th  digunakan untuk judul kolom/baris (teks tebal & rata tengah), sedangkan unset td  digunakan untuk isi data biasa (teks reguler & rata kiri).
3. unset colspan  berfungsi untuk menggabungkan dua atau lebih kolom menjadi satu sel secara horizontal.
4. unset form  berfungsi sebagai wadah untuk menampung elemen input guna mengumpulkan dan mengirim data dari pengguna ke server.
5. Radio Button hanya mengizinkan pengguna memilih satu dari beberapa pilihan, sedangkan Checkbox mengizinkan memilih lebih dari satu atau tidak memilih sama sekali.
6. Agar meningkatkan aksesibilitas (screen reader) dan memperluas area klik (pengguna bisa mengklik teks label untuk mengaktifkan input).
7. unset input type="text"  untuk teks pendek satu baris, sedangkan unset textarea  untuk teks panjang yang bisa memuat banyak baris dan ukurannya bisa diubah.
8. unset header : Pembuka halaman/logo.
unset nav : Menu navigasi utama.
unset main> : Konten utama halaman.
unset section : Bagian/bab konten yang spesifik.
unset article : Konten mandiri (seperti berita/blog).
unset aside : Konten sampingan/sidebar.
****: Penutup halaman/hak cipta.
9. unset required : Wajib diisi.
unset min  & unset max : Batas nilai angka/tanggal minimal dan maksimal.
unset minlength : Batas minimal jumlah karakter teks.
10. unset audio  khusus untuk memutar suara tanpa visual, sedangkan unset <video>  untuk memutar video (gambar dan suara) serta memiliki pengaturan area visual (width/height).
